
# Multiservicios Trébol - Sistema de Gestión de Taller 🍀

Este es un sistema de escritorio (Desktop) desarrollado en Java para la gestión integral de un taller mecánico. El sistema permite administrar desde el registro de clientes hasta servicios especializados de muelles, integrando el control de inventario de forma automática.

## 🚀 Lo que se tiene de momento

- **Gestión de Clientes:** Registro y búsqueda en tiempo real.
- **Control de Vehículos:** Vinculación de vehículos a sus respectivos dueños.
- **Órdenes de Trabajo:** El núcleo del sistema para el seguimiento de servicios y estatus.
- **Módulo de Muelles:** Registro técnico especializado con vinculación directa a órdenes.
- **Integración de Inventario:** Descuento automático de piezas al registrar servicios.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Java 17+
- **Gestor de Dependencias:** Maven
- **Base de Datos:** MariaDB
- **Interfaz Gráfica:** Swing (MVC - Modelo Vista Controlador)
- **Driver JDBC:** MariaDB Connector

## 📋 Requisitos previos

Antes de comenzar, asegúrate de tener instalado:
- JDK 17 o superior.
- Maven.
- PhPMyAdmin.

## 🔧 Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/MultiserviciosTrebol.git](https://github.com/tu-usuario/MultiserviciosTrebol.git)
   ```

2. **Configurar la base de datos:**
   - Importa el archivo `sql/database.sql` en el proyecto.

3. **Compilar el proyecto:**
   ```bash
   mvn clean install
   ```

4. **Ejecutar:**
   Inicia el sistema desde la clase `com.trebol.main.Main` o mediante el archivo ejecutable generado.
